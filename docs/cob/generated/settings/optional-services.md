Environment variables in the **Optional services** group. Set them in the `.env` file at the repository root (the template is `.env.example`) and restart the app, worker and mailer. Names start with `RAG_` unless noted.

## `COMPOSE_PROFILES`

Which optional containers start.

Default: `tei`. Read by Docker Compose, not the engine.

## `RAG_TRANSCRIPTION_PROVIDER`

Audio transcription. whisper_local needs the `transcription` profile; whisper_api uses OpenAI. off | whisper_api | whisper_local

Default: `off`.

## `RAG_WHISPER_API_KEY`

OpenAI key for RAG_TRANSCRIPTION_PROVIDER=whisper_api.

Default: secret, no default.

## `RAG_WHISPER_MODEL`

Model for whisper_api.

Default: `whisper-1`.

## `RAG_WHISPER_LOCAL_URL`

Where this machine reaches the Whisper container. Containers use http://whisper:9000 automatically.

Default: `http://whisper:9000`. `.env.example` sets `http://127.0.0.1:9010`.

## `RAG_WHISPER_LOCAL_MODEL`

Whisper model size for whisper_local: tiny | base | small | medium | large.

Default: `base`.

## `RAG_WHISPER_HOST_PORT`

Host port the Whisper container publishes.

Default: `9010`. Read by Docker Compose, not the engine.

## `RAG_WHISPER_IMAGE`

Whisper container image (CPU) and its GPU variant.

Default: `onerahmet/openai-whisper-asr-webservice:v1.9.1`. Read by Docker Compose, not the engine.

## `RAG_WHISPER_GPU_IMAGE`

Whisper container image (CPU) and its GPU variant.

Default: `onerahmet/openai-whisper-asr-webservice:v1.9.1-gpu`. Read by Docker Compose, not the engine.

## `RAG_LANGFUSE_ENABLED`

Observability (Langfuse): start the profile, open http://127.0.0.1:3002, create a project, paste its keys below and set RAG_LANGFUSE_ENABLED=true. true | false. Send traces to Langfuse.

Default: `false`.

## `RAG_LANGFUSE_PUBLIC_KEY`

Langfuse project public key (from the Langfuse UI).

Default: empty.

## `RAG_LANGFUSE_SECRET_KEY`

Langfuse project secret key (from the Langfuse UI).

Default: secret, no default.

## `RAG_LANGFUSE_HOST`

Where this machine reaches Langfuse. Containers use http://langfuse:3000 automatically.

Default: `http://127.0.0.1:3000`. `.env.example` sets `http://127.0.0.1:3002`.

## `RAG_LANGFUSE_DB_PASSWORD`

Password of Langfuse's own database (generated by `make setup`). Changing it signs you out.

Default: empty (generated by `make setup`).

## `RAG_LANGFUSE_NEXTAUTH_SECRET`

Keys the hashing of stored Langfuse API keys (generated). Changing it invalidates existing keys.

Default: empty (generated by `make setup`).

## `RAG_LANGFUSE_SALT`

Salt for Langfuse API keys (generated). Changing it invalidates existing keys.

Default: empty (generated by `make setup`).

## `RAG_LANGFUSE_URL`

Where a browser reaches the Langfuse UI.

Default: `http://localhost:3002`. Read by Docker Compose, not the engine.
