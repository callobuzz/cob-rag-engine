The harness reproduces the published model

Dense retrieval lands within 0.003 of bge-base's published nDCG@10 on five datasets and 0.012 above it on TREC-COVID. Chunking, the query instruction and the index lose nothing.

Hybrid wins on all six

A BM25 keyword leg with stemming, fused with dense search, beats the model alone everywhere and beats BM25 by a wide margin. No larger model, no LLM, nothing paid.

How you fuse decides whether hybrid helps

Reciprocal-rank fusion, the common default, lost to dense-only on five of six datasets. Weighted score fusion (0.75 dense, 0.25 keyword, normalized per query) wins on five and ties the sixth. The weight was chosen on BEIR's dev and train judgements and only then measured on test.

The reranker is a trade, not a free win

The cross-encoder lifts the question-answering sets (FiQA +0.013, TREC-COVID +0.048) and hurts the other four, ArguAna by 0.11. It costs about 0.3 s per query on a GPU and 15 s on CPU, so it ships off and is enabled per knowledge base.

Real documents

55 questions over the files customers actually upload

Seven files go through the same upload path a customer uses: parse, chunk, embed. Answers sit in prose, in tables, in spreadsheet cells, on slides, and on a scanned page that only OCR can read. Where RAGFlow is ahead

Document layout analysis with DeepDoc and template chunkers for papers, laws and slides; GraphRAG and RAPTOR; an agent canvas; more than twenty data connectors. If those matter most, it is an excellent choice.

Where this engine is ahead

Running a paid chatbot service for many businesses: scoped keys, metering, a hardened website widget and a small footprint. RAGFlow's share token and API key were mutually derivable before 0.22 (CVE-2025-69286), its documented minimum is 16 GB of RAM, and its vector search is filtered by the keyword match, which returns nothing for Thai queries (issue #17041).

Reproduce it

Run every number yourself

You need the stack running and Python 3.12 with httpx and pyarrow. The scripts read the admin key from your environment or the repository's .env. Long runs checkpoint: run the same command again to resume.

# GPU is optional; this overlay embeds in full precision, as published
docker compose -f docker-compose.yml -f docker-compose.gpu.yml \
  -f benchmarks/compose.local-embeddings.yml up -d --build

# BEIR: downloads ~330 MB, imports 272k documents, evaluates
python benchmarks/beir.py --datasets scifact,nfcorpus,arguana,scidocs,fiqa,trec-covid \
  --configs dense,hybrid,"hybrid(rrf)",hybrid+rerank --label mine
python benchmarks/fusion_study.py

# Real documents, security and operations, small policy set
python benchmarks/documents.py --label mine
python benchmarks/ops.py --label mine
python benchmarks/run.py --label mine

Retrieval benchmarks measure whether the right passage is found, not how an LLM words the answer. BEIR is English. Reference numbers for other models are their published results, not re-runs. Method and raw results: benchmarks/ in the repository.
